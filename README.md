
# LLM-Powered GitHub Documentation Automation

An LLM-powered automation tool that generates structured technical documentation for LeetCode solutions and pushes both the documentation and Python source code directly to GitHub.

The project uses **Ollama + Gemma 2** to generate detailed algorithm explanations locally, while the GitHub REST API handles direct file uploads to a remote repository.

## Key Features

- **Local LLM Integration:** Uses Gemma 2 (2B) through Ollama to generate documentation locally.
- **Automated Documentation:** Generates `approach.md` containing:
  - Problem overview
  - Intuition
  - Detailed algorithmic approach
  - Time complexity analysis
  - Space complexity analysis
- **Direct GitHub Integration:** Uploads generated Markdown documentation and Python solutions using the GitHub REST API.
- **Organized Repository Structure:** Automatically creates problem-specific directories under `Problems/`.
- **Zero Local File Storage:** Processes the problem statement, solution, and generated documentation in memory without writing them to local project files.
- **Environment-Based Configuration:** Uses environment variables to manage GitHub credentials securely.

## Prerequisites

Before running the application, install:

1. Python 3.9+
2. [Ollama](https://ollama.com/)
3. [Git](https://git-scm.com/)
4. A GitHub Personal Access Token with repository contents write permission.

Download the Gemma 2 model:

```bash
ollama pull gemma2:2b
```

Ensure Ollama is running before executing the application.

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Varma-N/llm-powered-github-documentation-automation.git

cd llm-powered-github-documentation-automation
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it:

**Windows:**

```bash
venv\Scripts\activate
```

**Linux/macOS:**

```bash
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

Create a `.env` file in the project root:

```env
GITHUB_TOKEN=your_github_personal_access_token
GITHUB_USERNAME=your_github_username
REPO_NAME=your_repository_name
```

Never commit your `.env` file or expose your GitHub token.

### 5. Run the application

```bash
python main.py
```

Enter the following details when prompted:

- Day number
- LeetCode problem number
- Problem title
- Problem statement
- Python solution

On Windows, finish each multiline input section with `Ctrl + Z`, followed by `Enter`. On Linux/macOS, use `Ctrl + D`.

The application generates the approach documentation using Gemma 2 and uploads both files directly to GitHub.

## Security Considerations

- GitHub credentials are loaded through environment variables.
- The application does not intentionally write problem statements, solutions, or generated documentation to local files.
- The LLM runs locally through Ollama.
- GitHub uploads are performed through authenticated HTTPS requests.
- Keep `.env` excluded from version control.

## Current Limitations

- Requires a locally running Ollama instance.
- Documentation quality depends on the LLM's interpretation of the problem and solution.
- The current GitHub upload implementation is designed for creating new files. Existing files at the same paths require SHA-based update handling.
- Generated complexity analysis should be reviewed for correctness.
